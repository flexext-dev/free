== Description ==

**FlexExt AI SEO Agent Readiness for WordPress** prepares your website for the generative search era and autonomous AI agents.

As search habits shift toward answer engines (ChatGPT, Anthropic Claude, Perplexity, Google Gemini), your website needs structured machine-readable summaries and clear crawler access rules. This plugin generates the official **`/llms.txt` proposal standard** and gives you fine-grained control over AI bot crawler policies via dynamic `robots.txt` injection.

### Key Features (100% Free):
* **Standard `/llms.txt` Generator:** Generates a clean, curated Markdown overview of your site for Large Language Models.
* **Smart Robots.txt AI Bot Manager:** 1-click toggles allowing or blocking specific AI crawlers (GPTBot, ChatGPT-User, ClaudeBot, PerplexityBot, Google-Extended, Applebot-Extended, Meta-ExternalAgent).
* **AI Agent Readiness Score:** In-dashboard checklist auditing your site's discoverability for generative AI engines.
* **Zero Dependencies:** Pure lightweight PHP/WordPress APIs, zero external requests, and no impact on frontend site performance.

== Installation ==

1. Download the `flexext-ai-seo.zip` package.
2. In your WordPress admin dashboard, navigate to **Plugins > Add New Plugin > Upload Plugin**.
3. Select `flexext-ai-seo.zip` and click **Install Now**.
4. Click **Activate Plugin**.
5. Configure bot permissions and `/llms.txt` settings under **AI SEO (Free)** in your WordPress admin menu.

== Frequently Asked Questions ==

= Does this plugin require any registration or license key? =
No. The Free edition is 100% open-source under GPLv2 and works out of the box with zero license keys or trial limitations.

= Where can I view the generated llms.txt? =
Once enabled, navigate to `https://your-domain.com/llms.txt` to view the plain text Markdown summary.
