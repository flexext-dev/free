1. **100% Native Joomla 4.x, 5.x & 6.x MVC Architecture:** Runs cleanly on PHP 8.1–8.4+ with **zero** Backward Compatibility (`plg_behaviour_compat`) plugin overhead and zero jQuery dependency.
2. **Built-in Light & Dark Theme Contrast Engine (WCAG 2.2 AA):** Semantic CSS variables ensure crisp readability on Cassiopeia, YOOtheme Pro, Helix Ultimate, and Astroid templates.
3. **Complete Unified Package (`pkg_flexext_store`):** Installs component, cart/search/category/currency modules, Smart Search (`plg_finder`) indexer, SEO canonical router, and Bank Transfer / Cash on Delivery payment plugins in one click.
4. **Seamless In-Place Upgrade Path:** Upgrade anytime to [Standard](https://flexext.dev/en-gb/product/flexext-store-standard-joomla), [PRO](https://flexext.dev/en-gb/product/flexext-store-pro-joomla), or [Ultimate](https://flexext.dev/en-gb/product/flexext-store-ultimate-joomla) (Przelewy24 BLIK, Stripe, PayPal, InPost Paczkomaty, EU Omnibus 30-day price history, PDF VAT invoices, AI SEO) without losing products or orders.
